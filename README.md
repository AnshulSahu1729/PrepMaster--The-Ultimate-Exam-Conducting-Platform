# PrepMaster-The Ultimate Exam Conducting Platform

PrepMaster is a platform in which Teachers can make tests and Students can attempt those tests. The Teachers can see the scores of the students. Students can also see their previous test scores in the dashboard.
Its makes the process of conducting the test and evaluating the marks faster and efficient.

#### 2.4 Attempting A Test  

To participate in a test, the student first enters the unique Test ID provided by the teacher. After entering a valid Test ID, the student can access the corresponding test.

Before the test begins, the student is presented with an Instructions screen containing important details about the examination, including:

- Test Name
- Marking Scheme
- Number of Questions

After reviewing the instructions, the student can begin the test. Each question is presented along with four multiple-choice options (A, B, C, and D). The student selects the option they believe is correct and clicks Submit to submit their answer.

The application immediately provides feedback indicating whether the selected answer is correct or incorrect. The student can then click Next to proceed to the following question and continue the test until all questions have been attempted.

Once the student completes the test, the application evaluates their responses according to the specified marking scheme and displays the final score. The result screen shows the marks obtained by the student along with a confirmation message indicating that the test has been successfully completed.
